# adsp-components-react

The React adapter for the ADSP application components: `AdspThemeProvider`, `useAdspTheme()` and
the React components themselves.

See [`../adsp-components-core/README.md`](../adsp-components-core/README.md) for what the framework
is, how an application consumes it, and how to add a component.

```bash
npx nx test adsp-components-react
npx nx lint adsp-components-react
```
