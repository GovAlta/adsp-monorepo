Quick start: cd apps/local-dev && npm install → node src/server.js → open http://localhost:3001

Real UI: In a second terminal: cd apps/planner-ui && npm run dev → open http://localhost:5173 (uses apps/planner-ui/.env.local to point at this stub server)

⚠ All data is in-memory and resets on server restart. JWT secret is local-dev-secret-not-for-prod — never use in production.
