# Alberta Digital Service Platform (ADSP)

ADSP is a platform of micro-services with a model for tenancy and a unified administration application for platform services. It includes micro-services and micro-apps that provide platform capabilities, in addition to the libraries to support the rapid development of platform and tenant components.

This monorepo uses the [Nx](https://nx.dev) toolstack.
